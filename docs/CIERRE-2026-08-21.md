## Lo logrado hoy

### 1. Marcas públicas
- Se ocultó **Chore-Time** y **Roxell** del sitio público.
- `/marcas/chore-time` redirige a `HomePage`.
- Se eliminó el botón de búsqueda pública de productos del `Header` porque solo exponía productos Chore-Time.

### 2. Backend — refactor y robustez
- Se creó `api/app/services/excel.py` para centralizar la lectura de archivos Excel.
- Se desacoplaron los routers de ventas, dashboard, cotizaciones y almacén para que usen el servicio compartido.
- Se reemplazó el caché en pickle por caché en **JSON** en disco.
- `api/app/database.py` ahora usa `ThreadedConnectionPool` para PostgreSQL.
- Las rutas de Excel se externalizaron a variables de entorno (`api/.env.example`).
- Se agregó validación de rutas de Excel al arrancar la aplicación.

### 3. Cotizador
- **Precio unitario:** ahora se muestra con formato de moneda (`$`, comas, 2 decimales) y se edita al hacer clic.
- **Envío en PDF:** se reemplazó la línea fija *"Estos precios son L.A.B. Su Granja"* por **Envío:** {leyenda de envío}; si no hay leyenda, no aparece.
- **Folio:** se genera con el **primer nombre del cliente** + fecha `YYMMDD` y se alinea a la izquierda en el PDF.
- **PDF al guardar:** ahora se abre automáticamente en una nueva pestaña del navegador.
- Botón posterior cambiado a **"Ver PDF"**.

### 4. Dashboard / Historial de ventas
- Los `SearchableSelect` ahora permiten navegar con **↓ / ↑** y seleccionar con **Enter**.
- El filtro de cliente en historial de ventas permite escribir texto libre y filtrar parcialmente.

### 5. San Antonio
- Al hacer clic en una **orden de compra** se muestra su material (partidas) en la sección inferior.
- Se agregaron filtros:
  - Búsqueda general de OC.
  - Búsqueda de OC por **código o descripción de material**.
  - Filtros de partidas por código/descripción y estado de línea.
- Estado vacío cuando no hay OC seleccionada.

### 6. Hotfix en producción
- Se corrigió error `Invalid currency code : [object Object]` en el Dashboard.
- Causa: `DataTable` pasaba el objeto `row` como segundo argumento a `formatCurrency`.
- Solución: las funciones de formato detectan si `moneda` es un objeto y usan `row.moneda` o caen a `MXN`.
