## 📝 Notas técnicas
- El nuevo endpoint de existencias usa `WHERE cve_art = ANY(%(codigos)s)` de PostgreSQL y lee el material en vales del mismo Excel que usa la sección de vales.
- El frontend precarga hasta 500 códigos del historial de ventas al montar el cotizador, pero ahora también consulta existencias para códigos agregados manualmente.
- Las fotos se leen desde el Excel de almacén (hoja `FOTOS_PRODUCTOS`) y se sirven a través del endpoint `/api/almacen/foto-producto/{codigo}`; el cotizador solo las muestra, no permite subirlas desde la web.
- El PDF con fotos agrega una columna de 60 × 45 puntos; si la imagen no existe, la celda muestra “—”.
- El folio se genera automáticamente al estilo `CLIENTE YYMMDD`; si ya existe, se usa sufijo `-2`, `-3`, etc.
